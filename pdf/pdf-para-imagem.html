    Qual resolução escolher

    72 ppp serve para tela, 150 ppp é um bom padrão e 300 ppp é indicado para impressão, com arquivos maiores.

    Baixar tudo de uma vez

    Quando houver várias páginas, baixe cada imagem ou todas juntas em um arquivo ZIP gerado no navegador.

    Nenhum arquivo sai do seu dispositivo. As ferramentas de PDF rodam no seu navegador com bibliotecas de código aberto (pdf-lib e PDF.js).
