    PDF para Word

    Tipo de conversão

    Funciona com PDFs que têm texto digital. PDFs escaneados (foto do papel) entram como imagem.

    Editável ou fiel ao visual?

    O modo Editável reconstrói parágrafos, títulos, listas, tabelas e imagens para você alterar no Word. O modo Fiel ao visual coloca cada página como imagem: a aparência fica idêntica, mas o texto não é editável.

    PDFs escaneados

    Se o PDF é uma foto do papel, não há texto digital para extrair: a página entra como imagem. O reconhecimento de texto (OCR) não está disponível nesta versão.
